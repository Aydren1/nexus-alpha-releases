# NEXUS Alpha Releases

Private friends-testing releases for the NEXUS Star Citizen competitive platform.

Download only from the [Releases](https://github.com/Aydren1/nexus-alpha-releases/releases) page and compare the downloaded ZIP against the published SHA-256 checksum before opening it.

NEXUS is an independent community project and is not affiliated with or endorsed by Cloud Imperium Games.

## Testers

Read the tester guide, privacy notice, and known issues before creating an account. This software is unfinished; accounts, ratings, events, and other alpha data may be reset.

Never post passwords, authentication tokens, private messages, or screenshots containing personal information in a bug report.

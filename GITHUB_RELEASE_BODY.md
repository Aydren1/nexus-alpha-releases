# NEXUS 0.5.0 Alpha 7.12 — Public Test

NEXUS is an open-registration competitive matchmaking alpha for Star Citizen. Anyone with this official release link can download the app, create an account, and verify a public RSI identity without a manual invitation. NEXUS is not affiliated with or endorsed by Cloud Imperium Games.

## What is included

- Larger opposing fighter silhouettes designed to remain recognizable at Windows taskbar size
- Full-canvas native Windows taskbar and application icons at 16, 24, 32, 48, 64, 128, and 256px
- Clickable weekly and community-event cards with a live single-elimination bracket view
- Real entrant RSI names and avatars, clearly marked open slots, join/withdraw controls, and organizer/admin winner advancement
- A clearer 72px signed-in sidebar logo with the lower fighter recolored to the NEXUS UI cyan
- RSI account verification through a public Citizen Dossier bio code
- Ranked 1v1, 3v3, and 5v5 queues with exact party-size enforcement
- Parties, shared channel chat, avatars, presence, rankings, and weekly tournaments
- Community events with admin approval
- Local match-evidence screenshots using a remembered global hotkey
- A single-window desktop launcher and logo-matched standard/night themes
- Missions and Channels unseen indicators that clear after the section is opened and stay cleared after restart
- Admin alerts only when a match result is disputed, with a direct link to the dedicated Admin dispute queue
- Match dispute review actions for approving the submitted result or voiding the match
- Lightweight minimized behavior that pauses visual animation work and slows the queue display timer
- Optional native Windows alerts for new shared-channel messages while NEXUS is minimized
- A built-in Minimize & Test Chat Alert action under Settings
- A larger, upward-balanced in-app logo rendered from the 512px master asset for sharper high-DPI displays
- Instant ranked-queue feedback with an inline connection pulse instead of a blocking cursor pause
- A shorter two-call cloud queue path with automatic UI rollback when the server rejects an entry
- Clean test data: no fabricated pilots, matches, ratings, queue counts, tournaments, organizations, mission progress, notifications, or chat messages
- Live Supabase records or clearly labeled empty states throughout the alpha
- Separate Ranked and Unranked 1v1, 3v3, and 5v5 matchmaking pools; Unranked never affects ELO

## Install

1. Download `NEXUS-0.5.0-alpha.7.12-win-x64.zip` from this release.
2. Confirm its SHA-256 value matches `SHA256SUMS.txt`.
3. Extract the entire ZIP to a normal folder such as `C:\Games\NEXUS Alpha 7.12`.
4. Open `NEXUS.exe`. Do not run it from inside the ZIP.
5. Because this friends build is unsigned, Windows may show **Windows protected your PC**. Confirm the download came from this release before choosing **More info → Run anyway**.

## Alpha warning

This software is unfinished. Rankings, events, and accounts may be reset. Do not reuse a sensitive password. Match screenshots remain local unless a future submission action clearly asks for consent.

Please report problems using the tester report template included with this release. Never post passwords, authentication tokens, private messages, or screenshots containing personal information.
